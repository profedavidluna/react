Cada carpeta de ejercicios contiene también un archivo `index.html` que puedes usar para ejecutar los scripts JavaScript.

## Cómo Usar Esta Guía

1.  **Clona el Repositorio:**
    ```bash
    git clone [https://github.com/tu-usuario/javascript_exercises.git](https://github.com/tu-usuario/javascript_exercises.git)
    cd javascript_exercises
    ```

2.  **Navega a la Carpeta del Ejercicio:**
    Por ejemplo, para los ejercicios básicos:
    ```bash
    cd 01_basics/
    ```

3.  **Abre el `index.html` en tu Navegador:**
    Simplemente arrastra el archivo `index.html` a tu navegador web o haz doble clic en él.

4.  **Abre la Consola del Desarrollador:**
    La mayoría de los ejercicios imprimen sus resultados en la consola del navegador. Para abrirla:
    * **Google Chrome / Firefox:** Presiona `F12` o `Ctrl+Shift+I` (Windows/Linux) / `Cmd+Opt+I` (Mac). Ve a la pestaña "Console" (Consola).

5.  **Edita el Archivo JavaScript:**
    Abre el archivo `.js` correspondiente al ejercicio que estás trabajando (ej. `01_variables_data_types.js`) en tu editor de código preferido.

6.  **Sigue las Instrucciones:**
    Dentro de cada archivo `.js`, encontrarás comentarios detallados con la descripción del ejercicio, las instrucciones, los puntos a cubrir y dónde debes escribir tu código.

7.  **Cambia el Script en `index.html` (si es necesario):**
    Si estás trabajando en un ejercicio diferente dentro de la misma carpeta (ej. `02_operators.js`), asegúrate de que el archivo `index.html` esté enlazando al script correcto. Solo una etiqueta `<script>` debe estar activa a la vez:
    ```html
    <script src="01_variables_data_types.js"></script>
    ```

8.  **Guarda y Recarga:**
    Después de hacer cambios en tu archivo `.js`, guarda el archivo y recarga la página `index.html` en tu navegador para ver los resultados actualizados en la consola.

## Recomendaciones para el Aprendizaje

* **Paso a Paso:** No intentes resolver todos los ejercicios a la vez. Ve sección por sección, ejercicio por ejercicio.
* **Comprende Antes de Codificar:** Lee bien las instrucciones y la descripción del ejercicio. Piensa en la lógica antes de escribir código.
* **Usa `console.log()`:** Es tu mejor amigo para depurar y entender lo que está pasando en tu código.
* **Experimenta:** No te limites a la solución del ejercicio. Cambia valores, prueba diferentes escenarios, y ve qué sucede.
* **Consulta la Documentación:** Si no recuerdas algo, consulta MDN Web Docs. Es un recurso invaluable.
* **¡Diviértete!** La mejor forma de aprender es disfrutando el proceso.
